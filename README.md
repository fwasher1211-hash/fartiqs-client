# Fartiqs Client

One Fabric mod (Minecraft 1.21.11) that contains Profit HUD, 2x Pay and Auction.

- Press **Right Shift** in game to open the menu.
- Click a card (or its switch) to turn that mod on/off. Everything starts OFF.
- Auction: the **Open** button opens the auction menu (Auction's own Right Shift key is disabled).
- Settings are saved to `config/fartiqs-client.properties`.

## Install
Put only `fartiqs-client-1.0.0.jar` (+ Fabric API) in your mods folder.
**Delete the standalone Profit HUD / 2x Pay / Auction jars** - they are already inside this one.

## Build
Push this folder to a GitHub repo, open the Actions tab, run "build", download the `fartiqs-client` artifact.
